Components — TV

10-foot controls at 1:1. Exactly one focused element per screen; focus = off-white fill or 4 px white ring + scale. No accent buttons on TV.

Buttons

Unfocused buttons are 0.12 white; the primary action wins by position and default focus.

Chips

Selected-but-not-focused = 0.16 fill. Focused = off-white fill, dark text.

Badges, indicators and key legend

Minimum text 18 px. Legend keycaps: 2 px 0.28 outline, radius 10.

Inputs

Text entry is full screen with the keyboard on the right; the PIN keypad replaces it for digits.

Selection and settings

Focus opens on the current option. “· Current” and “· unavailable” read after the label.
