VIPTV · TV

Use the arrow keys like a remote. Hold Enter to see the pressed state. Esc or Backspace goes back. You can also click.

What Android TV says

Google's TV focus system builds every focus state from four properties: scale, border, glow and colour, mixed per context (scale defaults 1.025×, 1.05×, 1.1×).

Compose for TV's Button default: focused container = onSurface and content = inverseOnSurface (it inverts to a light fill with dark text), and focusedScale = 1.1f. No border, no glow by default.

Elements also have a pressed state that lasts while the remote button is held, and a lower-prominence disabled state.

VIPTV focus (what to build)

  • Focused: fill #F4F2EE, text and icon #111113, shadow 0 18px 50px rgba(0,0,0,.45). Colours fade 150 ms. No scale: the inversion alone is the cue, and it is readable from the couch.
  • Default: glass, rgba(255,255,255,.16) with a 24px backdrop blur, text #F4F2EE.
  • Pressed (OK held): fill #DAD8D3.
  • Disabled: 38% opacity, and focus skips it.
  • Selected chip: check icon plus a 2px inner outline at 60% white. When focused it becomes the same white fill, still with the check.
  • Sizes: buttons 72px tall with 12px corners, icon buttons are 72px circles, chips are 56px pills, settings rows are 80px tall with 12px corners.

Compose for TV

// Text button (Play / Resume / settings row)
Button(
  onClick = onPlay,
  scale = ButtonDefaults.scale(focusedScale = 1f, pressedScale = 1f),   // no zoom
  colors = ButtonDefaults.colors(
    containerColor = Color.White.copy(alpha = 0.16f),
    contentColor = Color(0xFFF4F2EE),
    focusedContainerColor = Color(0xFFF4F2EE),
    focusedContentColor = Color(0xFF111113),
    pressedContainerColor = Color(0xFFDAD8D3),
    pressedContentColor = Color(0xFF111113),
  ),
  shape = ButtonDefaults.shape(RoundedCornerShape(12.dp)),
) { … }

// Icon button: same colours, IconButtonDefaults.scale(focusedScale = 1f), CircleShape, 72.dp
// Chip (FilterChip): same colours; selected = check icon + 2.dp inner border at 60% white

Down from Continue Watching

  • Key line: the focused row's title always sits at y 512 and its cards at y 564. The whole stack of rows slides up to put the next row on that line (350 ms, cubic-bezier(.2,0,0,1)).
  • Rows that leave: rows above the focused one fade out over 200 ms while they slide up under the billboard. Rows below stay fully visible.
  • Which card gets focus: the first time you enter a row, the card nearest on screen. When you come back, the card you left (Compose: Modifier.focusRestorer()).
  • Focus frame: a 3px white inner ring that fades in over 120 ms. Nothing scales and nothing moves when focus moves.
  • Posters show their title only while focused. Landscape cards always show title and progress.

Left and right, the billboard, going back

  • Left and right: the frame moves across the visible cards. The row scrolls by one card (300 ms) only when focus reaches the second-to-last visible card, so a peeking card always shows there's more.
  • Billboard (top of the screen): waits until focus has rested for 400 ms, then crossfades art and text over 300 ms, so holding Down never flickers it.
  • Holding a key: every animation picks up from where it currently is, with no queue, and focus is never blocked by motion.
  • Hero → Continue Watching (and back up): the hero lifts 80px and fades while the row travels up, 450 ms emphasized. The top tabs fade over 200 ms.
  • Back from any row returns to the top of Home in one move.
  • When the TV asks for reduced motion, every slide becomes a cut.
